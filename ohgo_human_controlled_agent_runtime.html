04. CORE ARCHITECTURAL INVARIANTS

Non-negotiable rules governing runtime authority, sessions, and persistence.

I1-I4. THREE AUTHORITIES RUNTIME

Exactly three primary workspaces (ASK, FUZZ, BUILD). BUILD is the sole mutation authority. ASK & FUZZ can never mutate code.

I5 & I14. MODEL UNTRUSTED POLICY

Model output is untrusted proposal. The runtime capability policy enforces boundaries below the UI regardless of model intent or prompts.

I6 & I17. EPHEMERAL $SUP SUPPORT

$sup opens a quick reference query layer on the SUP model role. It never alters main task history, persistent context, or workspace state.

I8 & I10. SESSION TRUTH PERSISTENCE

Sessions retain resolved effective models across restarts in ~/.ohgo/sessions.db. Unfinished states resume truthfully; unknown stays unknown.

I11. PROJECT IDENTITY METADATA

<root>/.ohgo/project.yml establishes stable project identification without duplicating global session storage databases.

I18. AUDIT-FIRST SEAMS ENGINE

Existing execution engine is preserved. Architectural changes occur only at defined seams through audit, minimal change, and verification.
